My project, called SkyFrame, is about designing and building my own drone from scratch. The goal is to learn how drones work by designing the frame, understanding the electronic components, and learning how to program the drone. I am using Onshape to create a 3D model of my drone and researching the different parts needed to build it. Through this project, I want to improve my skills in engineering, coding, and problem-solving while creating a working drone of my own
